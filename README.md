# Simulation Decomposition (SimDec) Empirical Data Analysis
My Master's thesis applies Simulation Decomposition (SimDec) to empirical data and compares it with conventional statistical methods. The datasets and Python code for the analyses are included here.
The full thesis is available at LUTPub: [Simulation decomposition as a novel approach for empirical data analysis and visualization through comparison with statistical techniques]
## Files
### NYC Housing
- New York City housing sales dataset
- Python code for multiple linear regression and data preparation for SimDec
- Data source: [NYC Open Data](https://data.cityofnewyork.us/Housing-Development/NYC-Calendar-Sales-Archive-/uzf5-f8n2/about_data)
### Bank Marketing
- Bank marketing dataset
- Python code for SVM classification and data preparation for SimDec
- Data source: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/222/bank+marketing)
### Iris
- Iris dataset
- Python code for k-means clustering and data preparation for SimDec
- Data source: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/53/iris)
